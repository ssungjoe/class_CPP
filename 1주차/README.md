## C++ 언어의 탄생과 발전

- 1979년 AT&T 벨 연구소의 비야네 스트롭스트룹(Bjarne Stroustrup)이 착수한 'C with Classes' 연구에서 출발함.
- 1985년 《The C++ Programming Language》 출판부터 'C++'의 시작으로 봄.
- 1998년 C++ 국제 표준 언어 규격 제정 (C++98).

<br>

## C언어에는 없는 C++의 핵심 추가 개념 (중요)

- **클래스와 상속** : 클래스 및 상속 클래스를 지원함.
- **접근 제어** : 멤버 함수와 변수 접근 제어(`public`, `private`)가 추가됨.
- **생명주기 관리** : 객체의 생성자와 소멸자 개념이 도입됨.
- **프렌드(friend)** : 프렌드 클래스 기능이 있음.
- **안정성 향상** : 형식 검사와 함수 인자 변환 기능이 포함됨.
- **성능 최적화** : 인라인 함수를 지원함.
- **편의성 향상** : 기본 인잣값, 연산자 오버로딩 기능이 추가됨.
- **확장 기능** : 예외 처리, 템플릿, STL 같은 새로운 기능이 전반에 걸쳐 계속 추가됨.

<br>

## C++ 언어의 주요 특징

- **객체지향 프로그래밍**
  - 처리할 데이터와 처리 방법을 '객체(object)'라는 논리 단위로 모두 포함함.
- **낮은 수준 액세스와 추상화**
  - C언어처럼 시스템에 직접 접근할 수 있고, 데이터를 추상화하여 접근할 수도 있음.
  - 프로그램이 동작하는 시스템의 하드웨어에 직접 접근하여 제어할 수 있음.
  - 메모리도 개발자가 프로그래밍으로 직접 관리하여 매우 효율적인 프로그램을 개발할 수 있음.
- **데이터 추상화와 범용성**
  - 다양한 데이터와 구조를 처리할 수 있는 범용성을 지님.
  - AT&T 벨 연구소는 개발 이후 소유권을 독점하지 않아 C++가 외부에서 개발되는 것을 장려함.

<br>

## C++ 프로그램 빌드 과정

- `전처리 (Pre-processing)` : 소스 파일이 컴파일되기 전에 헤더파일 포함, `#define` 변경 등의 작업을 수행함.
- `컴파일 (Compile)` : 소스 코드를 컴퓨터(프로세서)가 이해할 수 있는 오브젝트 코드(object code)로 변경하는 과정임.
- `링킹 (Linking)` : 라이브러리 및 여러 개 소스 코드의 오브젝트 코드를 하나로 연결하여 실행 파일을 만드는 과정임.

<br>

## 첫 번째 C++ 프로그램

- `iostream` : C++의 표준 입출력을 다루기 위한 헤더 파일.
- `std::cout`, `<<` : 화면에 데이터를 출력하기 위해 사용하는 C++의 객체와 연산자.

```cpp
#include <iostream>

int main()
{
    std::cout << "Hello World!\n";
}
```
